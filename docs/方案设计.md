# 万能视频下载网站 - 方案设计文档

## 1. 技术架构

```
┌──────────────────────────────────────────────────────────┐
│                     用户浏览器（含移动端）                 │
│  ┌─────────────────────────────────────────────────────┐ │
│  │           Vue3 + Vite + Tailwind CSS v4             │ │
│  │  URL 输入 → 解析展示 → 格式选择 → Blob 下载          │ │
│  └──────────────────────┬──────────────────────────────┘ │
└─────────────────────────┼────────────────────────────────┘
                          │ HTTP API
┌─────────────────────────┼────────────────────────────────┐
│                  FastAPI 后端（Python）                      │
│  ┌──────────────────────┴──────────────────────────────┐ │
│  │  Platform Router                                     │ │
│  │    抖音 → douyin.py                                  │ │
│  │    B站  → bilibili.py                                │ │
│  │    其他 → downloader.py (yt-dlp)                     │ │
│  └─────────────────────────────────────────────────────┘ │
│  临时目录 downloads/ （shutdown 自动清理）                  │
└──────────────────────────────────────────────────────────┘
```

## 2. 技术栈选型

| 层次 | 技术 | 选型理由 |
|------|------|----------|
| 前端 | Vue 3 + Vite 7 + Tailwind CSS v4 | 轻量、开发快、响应式友好 |
| 后端 | FastAPI + Uvicorn | 异步高性能、Python 生态 |
| 下载引擎 | yt-dlp | 14w+ Star，1800+ 平台 |
| 国内平台 | douyin.py + bilibili.py | 专用公开 API，绕过反爬 |
| 媒体合并 | ffmpeg（系统依赖） | YouTube 等 A/V 分离合并 |
| AI（第 4 阶段） | DeepSeek + openai SDK + faster-whisper | 流式摘要、字幕转写 |
| 认证（后续） | JWT + bcrypt + SQLite | 轻量持久化 |
| 支付（后续） | Stripe Checkout | 国际标准 |

## 3. API 设计（第一期）

### 3.1 解析视频

```
POST /api/parse
{ "url": "https://..." }

→ 200 { "success": true, "data": { id, title, thumbnail, formats[], ... } }
→ 400 { "success": false, "error": "..." }
```

### 3.2 下载视频

```
POST /api/download
{ "url": "...", "format_id": "bestvideo+bestaudio/best" }

→ FileResponse (application/octet-stream)
```

### 3.3 获取直链

```
POST /api/direct-url
{ "url": "...", "format_id": "..." }

→ { "success": true, "data": { direct_url, ext, filesize } }
```

### 3.4 缩略图代理

```
GET /api/proxy/thumbnail?url=...

→ 图片流（绕过防盗链）
```

### 3.5 健康检查

```
GET /api/health → { "status": "ok", "ffmpeg": bool, "ai_available": bool }
```

### 3.6 下载字幕（第 4 阶段扩展）

```
POST /api/subtitles/download
{ "url": "...", "format": "srt" | "vtt" | "txt" }

→ FileResponse（字幕文件）
→ 响应头 X-Transcript-Source: subtitle | whisper
```

### 3.7 AI 分析（第 4 阶段）

```
POST /api/analyze          → { session_id, ... }
GET  /api/analyze/{id}/stream  → SSE（transcript / summary / mindmap）
POST /api/analyze/{id}/chat    → SSE 多轮问答
```

## 4. 平台路由与统一响应格式

所有 parser 返回相同 schema，前端平台无关：

```python
{
    "id", "title", "thumbnail", "duration", "duration_string",
    "uploader", "platform", "view_count", "upload_date", "description",
    "formats": [{
        "format_id", "ext", "resolution", "height",
        "label", "has_audio", "filesize"
    }],
    "subtitles": [...],
    "automatic_captions": [...]
}
```

路由优先级：`抖音 URL → B站 URL → yt-dlp 通用`

## 5. 前端 UI 设计（painting 风格）

参考 [ai.codefather.cn/painting](https://ai.codefather.cn/painting)：

| 元素 | 规范 |
|------|------|
| 页面背景 | `#F7F8FA` 浅灰 |
| 主色 | `#3B82F6` 饱和蓝 |
| 卡片 | 白色、`rounded-2xl`、轻阴影 |
| 标题 | 「万能视频下载，**一键保存**」— 关键词蓝色 |
| 输入框 | 全宽胶囊形 `rounded-full`，内嵌蓝色按钮 |
| 标签 | hashtag 风格 `#YouTube • #1080P • #无水印` |
| Header | 汉堡菜单 + 居中 Logo + 用户头像 |
| 转化区 | 功能卡片 + 免费/VIP 对比定价 |

### 页面结构

1. **Header** — 导航 + Logo + 登录入口（占位）
2. **Hero** — 大标题 + 胶囊 URL 输入
3. **VideoResult** — 解析结果（缩略图 + 格式 + 下载）
4. **PlatformSection** — 平台卡片网格（painting 卡片风格）
5. **FeatureSection** — 5 大特性
6. **HowToSection** — 三步使用指南
7. **PricingSection** — 免费 vs VIP（UI 占位，后续接入）
8. **Footer** — 免责声明

## 8. 风险与应对

| 风险 | 应对 |
|------|------|
| B 站 412 反爬 | bilibili.py 专用公开 API |
| 抖音 WAF | WAF 解算 + 分享页回退 |
| 移动端大文件超时 | Axios timeout 600s + 进度提示 |
| 服务器带宽 | 后续优先 direct-url 直链 |
| 版权合规 | Footer 免责声明 |
