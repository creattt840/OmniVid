# 本地运行指南

## 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 后端运行 |
| Node.js | 18+ | 前端开发 |
| ffmpeg | 任意 | YouTube 等 A/V 合并（推荐安装） |

## 1. 启动后端

> **Windows 注意**：若系统默认 `python` 为 3.8 等旧版本，请使用 3.10+（例如 `py -3.14`）。可先执行 `python --version` 确认。

```powershell
cd backend
py -3.14 -m pip install -r requirements.txt
py -3.14 -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

未安装依赖时会报 `No module named uvicorn`，先执行 `pip install -r requirements.txt` 即可。

验证：浏览器访问 http://localhost:8000/api/health ，应返回 `{"status":"ok",...}`

API 文档：http://localhost:8000/docs

## 2. 启动前端

新开一个终端：

```powershell
cd frontend
npm install
npm run dev
```

浏览器访问 http://localhost:5173

前端通过 Vite 代理将 `/api` 请求转发到后端 `:8000`。

## 3. 测试流程

1. 在首页搜索框粘贴视频链接（可点「试试：Bilibili」快速填入）
2. **抖音/B站分享口令**：可直接粘贴 App 复制的整段文案（含标题、话题、提示语），前端会自动提取其中的 `https://` 链接再解析
2. 未解析时，输入框下方可预览 **AI 分析成果演示**（可切换 3 条样例视频）
3. 点击「解析」，等待视频信息与 AI 分析同屏展示
3. 右栏自动开始生成摘要（无需额外点击）
4. 左栏选择清晰度，点击「立即下载」
5. 若视频有可用的字幕/转录，左栏显示 **「下载字幕」** 并导出 SRT；纯音乐/默剧等无法转录的视频不显示该按钮

**非视频链接**：输入普通网页地址（如工具站首页）时，前端弹窗提示「请输入视频链接」，不会发起解析。

### 本地视频上传

1. 点击左上角汉堡菜单 → **本地视频上传**
2. 拖拽或选择本地视频/音频（MP4、MKV、MOV、MP3 等，最大 500MB / 60 分钟）
3. 可选：同时上传 SRT/VTT 外挂字幕（有字幕可跳过 Whisper，分析更快）
4. 点击「开始分析」，左栏页内预览 + 右栏自动 AI 总结
5. 点击章节时间戳可跳转播放器对应位置

**注意**：上传文件在服务端临时保存 30 分钟，过期需重新上传。开发环境下上传请求直连 `:8000`（绕过 Vite 代理大文件限制）。

### AI 视频分析

解析成功后右栏自动触发，包含五个 Tab：

1. **摘要** — 流式生成结构化摘要、要点、章节、术语
2. **转录** — 带时间戳字幕，支持导出 SRT / VTT / TXT
3. **思维导图** — 全屏查看，导出 PNG / SVG / Markdown
4. **文章** — AI 将口语转写改写成书面文章
5. **AI 问答** — 基于视频内容多轮对话（Markdown 排版渲染）

**前置条件**：在 `backend/.env` 中配置 `DEEPSEEK_API_KEY`（参考 `.env.example`）。

### 首页成果演示

未解析视频时，Hero 下方展示预置的 AI 分析样例（摘要 / 转录 / 思维导图 / 文章），左栏可「切换演示视频」。数据来自 `frontend/src/data/demo-showcases.json`，纯静态只读，不消耗 AI 配额。

新增或更新演示数据：

## 4. 常见问题

**解析失败**
- 检查链接是否完整、视频是否为 **视频页面地址**（非首页/文章页）
- 粘贴非视频链接时会弹窗提示，请改用 B站 / YouTube / 抖音等视频 URL
- B 站/抖音走专用解析，其他平台依赖 yt-dlp
- 运行 `pip install -U yt-dlp` 更新到最新版

**YouTube 下载只有视频没有声音**
- 需要安装 ffmpeg 并加入 PATH
- 健康检查 `/api/health` 中 `ffmpeg: true` 表示已检测到

**上传失败 / 格式不支持**
- 仅支持 mp4、mkv、mov、webm、avi、mp3、m4a、wav、aac、ogg
- 单文件不超过 500MB，时长不超过 60 分钟
- 字幕仅支持 srt、vtt 格式

**AI 分析失败**
- 确认 `backend/.env` 已配置有效的 `DEEPSEEK_API_KEY`
- 访问 `/api/health` 检查 `ai_available: true`
- 无字幕视频首次需下载 Whisper 模型，请耐心等待（已优化：B站纯音频轨、beam_size=1、启动预热，详见 [阶段总结-无字幕解析提速](阶段总结-无字幕解析提速.md)）
- YouTube 无字幕时会走语音转写，需安装 ffmpeg
- **纯音乐 / 默剧 / 无对白视频**会被质量门控拒绝，提示「未检测到足够的人声内容」——属预期行为，详见 [测试报告](测试报告-无语音视频幻觉评估.md)
- 此类视频左栏 **不显示「下载字幕」** 按钮

**下载超时**
- 大文件下载可能需要数分钟，前端超时设为 10 分钟
- 字幕下载（含 Whisper）同样最长等待 10 分钟
- 检查网络连接

**点击下载后在新标签页播放而非保存**
- 已修复：优先 fetch 直链为 Blob 下载；CDN 跨域失败时自动走服务端代理
- Toast 会提示「直链下载已开始」或「下载已开始（服务端代理）」

**思维导图导出失败**
- 请等待思维导图渲染完成后再点击下载
- PNG/SVG 依赖 `html-to-image`，需在现代浏览器中使用

## 6. 用户登录与配额

### 6.1 配置环境变量

复制 `backend/.env.example` 为 `backend/.env`，除 AI 配置外还需填写：

```env
JWT_SECRET=<用 openssl rand -hex 32 生成>
DATABASE_URL=sqlite:///./omnivid.db
FREE_DAILY_AI_LIMIT=10
FRONTEND_URL=http://localhost:5173

# QQ 邮箱 SMTP（注册/登录/找回密码验证码）
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USER=你的QQ号@qq.com
SMTP_PASSWORD=QQ邮箱16位授权码
SMTP_FROM=你的QQ号@qq.com
SMTP_USE_SSL=true
```

**QQ 邮箱授权码获取**：QQ 邮箱 → 设置 → 账户 → 开启 SMTP 服务 → 生成授权码（不是 QQ 登录密码）。

### 6.2 使用说明

1. 打开 http://localhost:5173 ，点击右上角注册/登录
2. **注册**：填写邮箱 → 获取验证码 → 输入验证码 + 密码 → 注册
3. **登录**：支持「密码登录」或「验证码登录」两种方式
4. **忘记密码**：登录页点击「忘记密码？」→ 邮箱收码 → 设置新密码
5. 登录后可使用 AI 分析、改写、字幕翻译、PDF 导出、云端分析历史
6. 每个账号 **每日 10 次** AI 分析；账号菜单显示「今日 AI 分析 x/10」
7. 分析历史保存在服务端，每用户最多 10 条，换设备登录仍可查看
8. 定价区「免费使用」需登录；已登录后点击「立即使用」会滚动至顶部 URL 输入框

### 6.5 常见问题

**今日 AI 次数已用完**
- 每账号每日 10 次，UTC+8 自然日重置（以服务器日期为准）
- 账号菜单可查看「今日 AI 分析 x/10」

**未登录解析视频后登录，AI 仍显示「请先登录」**
- 登录成功后会自动重试 AI 分析；若未触发，刷新页面重新解析

**点击 Header 账号区域**
- 展开账号下拉菜单（今日用量、退出登录）

**收不到验证码邮件**
- 检查 `backend/.env` 中 SMTP 配置是否正确（授权码不是 QQ 密码）
- 查看垃圾箱；邮件标题为「OmniVid 验证码」
- 60 秒内不可重复发送，需等待倒计时结束
- 后端返回「邮件发送失败」时，确认 SMTP 端口 465 + `SMTP_USE_SSL=true`

**老账号兼容**
- 升级前已注册的账号仍可直接密码登录，无需补验证邮箱
