# 本地运行指南

## 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 后端运行 |
| Node.js | 18+ | 前端开发 |
| ffmpeg | 任意 | YouTube 等 A/V 合并（推荐安装） |

## 1. 启动后端

```powershell
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

验证：浏览器访问 http://localhost:8000/api/health ，应返回 `{"status":"ok",...}`

API 文档：http://localhost:8000/docs

## 2. 启动前端

新开一个终端：

```powershell
cd frontend
npm install
npm run dev
```

浏览器访问 http://localhost:5173

前端通过 Vite 代理将 `/api` 请求转发到后端 `:8000`。

## 3. 测试流程

1. 在首页搜索框粘贴视频链接（可点「试试：Bilibili」快速填入）
2. 点击「解析」，等待视频信息与 AI 分析同屏展示
3. 右栏自动开始生成摘要（无需额外点击）
4. 左栏选择清晰度，点击「立即下载」
5. 点击 **「下载字幕」** 可单独导出 SRT（无字幕时走 Whisper 转写，耗时较长）

### 本地视频上传

1. 点击左上角汉堡菜单 → **本地视频上传**
2. 拖拽或选择本地视频/音频（MP4、MKV、MOV、MP3 等，最大 500MB / 60 分钟）
3. 可选：同时上传 SRT/VTT 外挂字幕（有字幕可跳过 Whisper，分析更快）
4. 点击「开始分析」，左栏页内预览 + 右栏自动 AI 总结
5. 点击章节时间戳可跳转播放器对应位置

**注意**：上传文件在服务端临时保存 30 分钟，过期需重新上传。开发环境下上传请求直连 `:8000`（绕过 Vite 代理大文件限制）。

### AI 视频分析

解析成功后右栏自动触发，包含四个 Tab：

1. **摘要** — 流式生成结构化摘要、要点、章节、术语
2. **转录** — 带时间戳字幕，支持导出 SRT / VTT / TXT
3. **思维导图** — 全屏查看，导出 PNG / SVG / Markdown
4. **AI 问答** — 基于视频内容多轮对话

**前置条件**：在 `backend/.env` 中配置 `DEEPSEEK_API_KEY`（参考 `.env.example`）。

## 4. 常见问题

**解析失败**
- 检查链接是否完整、视频是否存在
- B 站/抖音走专用解析，其他平台依赖 yt-dlp
- 运行 `pip install -U yt-dlp` 更新到最新版

**YouTube 下载只有视频没有声音**
- 需要安装 ffmpeg 并加入 PATH
- 健康检查 `/api/health` 中 `ffmpeg: true` 表示已检测到

**上传失败 / 格式不支持**
- 仅支持 mp4、mkv、mov、webm、avi、mp3、m4a、wav、aac、ogg
- 单文件不超过 500MB，时长不超过 60 分钟
- 字幕仅支持 srt、vtt 格式

**AI 分析失败**
- 确认 `backend/.env` 已配置有效的 `DEEPSEEK_API_KEY`
- 访问 `/api/health` 检查 `ai_available: true`
- 无字幕视频首次需下载 Whisper 模型，请耐心等待
- YouTube 无字幕时会走语音转写，需安装 ffmpeg

**下载超时**
- 大文件下载可能需要数分钟，前端超时设为 10 分钟
- 字幕下载（含 Whisper）同样最长等待 10 分钟
- 检查网络连接

**思维导图导出失败**
- 请等待思维导图渲染完成后再点击下载
- PNG/SVG 依赖 `html-to-image`，需在现代浏览器中使用

## 5. 生产构建

```powershell
cd frontend
npm run build
```

构建产物在 `frontend/dist/`，可部署到 Nginx 等静态服务器，并反向代理 `/api` 到后端。
