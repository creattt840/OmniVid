# 本地运行指南

## 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 后端运行 |
| Node.js | 18+ | 前端开发 |
| ffmpeg | 任意 | YouTube 等 A/V 合并（推荐安装） |

## 1. 启动后端

```powershell
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

验证：浏览器访问 http://localhost:8000/api/health ，应返回 `{"status":"ok",...}`

API 文档：http://localhost:8000/docs

## 2. 启动前端

新开一个终端：

```powershell
cd frontend
npm install
npm run dev
```

浏览器访问 http://localhost:5173

前端通过 Vite 代理将 `/api` 请求转发到后端 `:8000`。

## 3. 测试流程

1. 在首页搜索框粘贴视频链接（可点「试试：Bilibili」快速填入）
2. 点击「解析」，等待视频信息与 AI 分析同屏展示
3. 右栏自动开始生成摘要（无需额外点击）
4. 左栏选择清晰度，点击「立即下载」
5. 点击 **「下载字幕」** 可单独导出 SRT（无字幕时走 Whisper 转写，耗时较长）

### 本地视频上传

1. 点击左上角汉堡菜单 → **本地视频上传**
2. 拖拽或选择本地视频/音频（MP4、MKV、MOV、MP3 等，最大 500MB / 60 分钟）
3. 可选：同时上传 SRT/VTT 外挂字幕（有字幕可跳过 Whisper，分析更快）
4. 点击「开始分析」，左栏页内预览 + 右栏自动 AI 总结
5. 点击章节时间戳可跳转播放器对应位置

**注意**：上传文件在服务端临时保存 30 分钟，过期需重新上传。开发环境下上传请求直连 `:8000`（绕过 Vite 代理大文件限制）。

### AI 视频分析

解析成功后右栏自动触发，包含五个 Tab：

1. **摘要** — 流式生成结构化摘要、要点、章节、术语
2. **转录** — 带时间戳字幕，支持导出 SRT / VTT / TXT
3. **思维导图** — 全屏查看，导出 PNG / SVG / Markdown
4. **文章** — AI 将口语转写改写成书面文章
5. **AI 问答** — 基于视频内容多轮对话（Markdown 排版渲染）

**前置条件**：在 `backend/.env` 中配置 `DEEPSEEK_API_KEY`（参考 `.env.example`）。

## 4. 常见问题

**解析失败**
- 检查链接是否完整、视频是否存在
- B 站/抖音走专用解析，其他平台依赖 yt-dlp
- 运行 `pip install -U yt-dlp` 更新到最新版

**YouTube 下载只有视频没有声音**
- 需要安装 ffmpeg 并加入 PATH
- 健康检查 `/api/health` 中 `ffmpeg: true` 表示已检测到

**上传失败 / 格式不支持**
- 仅支持 mp4、mkv、mov、webm、avi、mp3、m4a、wav、aac、ogg
- 单文件不超过 500MB，时长不超过 60 分钟
- 字幕仅支持 srt、vtt 格式

**AI 分析失败**
- 确认 `backend/.env` 已配置有效的 `DEEPSEEK_API_KEY`
- 访问 `/api/health` 检查 `ai_available: true`
- 无字幕视频首次需下载 Whisper 模型，请耐心等待
- YouTube 无字幕时会走语音转写，需安装 ffmpeg

**下载超时**
- 大文件下载可能需要数分钟，前端超时设为 10 分钟
- 字幕下载（含 Whisper）同样最长等待 10 分钟
- 检查网络连接

**点击下载后在新标签页播放而非保存**
- 已修复：优先 fetch 直链为 Blob 下载；CDN 跨域失败时自动走服务端代理
- Toast 会提示「直链下载已开始」或「下载已开始（服务端代理）」

**思维导图导出失败**
- 请等待思维导图渲染完成后再点击下载
- PNG/SVG 依赖 `html-to-image`，需在现代浏览器中使用

## 6. 用户登录与 VIP 支付（Stripe）

### 6.1 配置环境变量

复制 `backend/.env.example` 为 `backend/.env`，除 AI 配置外还需填写：

```env
JWT_SECRET=<用 openssl rand -hex 32 生成>
DATABASE_URL=sqlite:///./omnivid.db
STRIPE_SECRET_KEY=sk_test_xxx
STRIPE_WEBHOOK_SECRET=whsec_xxx
STRIPE_PRICE_ID=price_xxx
FRONTEND_URL=http://localhost:5173
HTTPS_PROXY=http://127.0.0.1:7890
```

### 6.2 Stripe Dashboard 配置（Test mode）

1. 注册 [Stripe Dashboard](https://dashboard.stripe.com/register)（需代理）
2. 保持左上角 **Test mode** 开启
3. **Product catalog** → 创建产品 `OmniVid VIP`，定价 **One-time CNY ¥9.90**，复制 `price_xxx`
4. **Developers → API keys** 复制 `sk_test_xxx`

### 6.3 安装 Stripe CLI（本地 Webhook）

```powershell
# 安装：https://docs.stripe.com/stripe-cli
stripe login
stripe listen --forward-to http://localhost:8000/api/billing/webhook
```

CLI 启动后会输出 `whsec_xxx`，填入 `STRIPE_WEBHOOK_SECRET`。

> 注意：本地开发必须用 CLI 转发的 `whsec`，与 Dashboard 里配置的 Webhook Secret **不同**。

### 6.4 三个终端联调

支付成功后 Stripe 会跳回 `FRONTEND_URL`（默认 `http://localhost:5173`）。请确保前端实际运行端口与之一致：

- `npm run dev` → 端口 **5173**
- `npm run preview` → 先 `vite build` 再预览，端口 **5173**（与 `FRONTEND_URL` 一致）

```powershell
# 终端 1：后端（带代理访问 Stripe）
$env:HTTPS_PROXY="http://127.0.0.1:7890"
cd backend
python -m uvicorn main:app --reload --port 8000

# 终端 2：前端
cd frontend
npm run dev

# 终端 3：Stripe Webhook 转发
stripe listen --forward-to http://localhost:8000/api/billing/webhook
```

### 6.5 测试支付流程

1. 打开 http://localhost:5173 ，点击右上角登录/注册
2. 滚动到定价区，点击 **开通 VIP**
3. 跳转 Stripe 测试支付页，使用测试卡：`4242 4242 4242 4242`，任意未来日期 + CVC
4. 支付成功后回到首页，Header 显示 **VIP** 徽章
5. 在 Stripe CLI 终端应看到 `checkout.session.completed` 事件

### 6.8 常见问题

**支付成功但 VIP 未开通**
- 确认 `stripe listen` 正在运行，且 CLI 输出的 `whsec` 已写入 `.env`
- 后端日志中 Webhook 应返回 `200`，若出现 `500` 需检查 `checkout.session.completed` 处理
- 支付成功后刷新页面，或重新登录查看 VIP 状态

**支付成功跳转「localhost 拒绝连接」**
- `FRONTEND_URL` 必须与前端实际端口一致（开发/预览均为 5173）
- 使用 `npm run preview` 时会自动先执行 build

**未登录解析视频后登录，AI 仍显示「请先登录」**
- 登录成功后会自动重试 AI 分析；若未触发，刷新页面重新解析

**点击 Header 账号区域**
- 展开账号下拉菜单（VIP 状态、续费、退出），不会跳转定价区
