# 阶段总结 - 邮箱验证码登录

## 1. 交付内容

### 后端

| 模块 | 路径 | 说明 |
|------|------|------|
| 验证码表 | `app/db/models.py` | `email_verification_codes`：邮箱、用途、哈希、过期、尝试次数 |
| 发邮件 | `app/services/email.py` | QQ SMTP（465 SSL / 587 STARTTLS） |
| 验证码服务 | `app/services/verification.py` | 生成、频率限制、验码、作废 |
| 认证 API | `app/api/auth.py` | `send-code` / 改造 `register`·`login` / 新增 `reset-password` |
| Schema | `app/schemas/auth.py` | 请求体校验（密码/验证码二选一登录） |
| 配置 | `app/core/config.py`, `.env.example` | SMTP 与验证码策略 env |
| 测试 | `tests/test_auth_email.py`, `tests/conftest.py` | mock 邮件发送，11 项验证码场景 |

### 前端

| 组件/模块 | 说明 |
|-----------|------|
| `AuthModal.vue` | 注册（邮箱+验证码+密码）、默认密码登录、底部切换验证码登录、忘记密码 |
| `api/auth.js` | `sendCode` / `resetPassword`，`login` 支持 code |
| `useAuth.js` | 暴露 sendCode、resetPassword |

## 2. API 一览

```
POST /api/auth/send-code       { email, purpose: register|login|reset_password }
POST /api/auth/register        { email, password, code }
POST /api/auth/login           { email, password } 或 { email, code }
POST /api/auth/reset-password  { email, code, new_password }
GET  /api/auth/me              （不变）
```

## 3. 安全策略

- 验证码 6 位数字，bcrypt 哈希入库，5 分钟过期
- 同一邮箱 60 秒内只能发 1 次
- 单码最多 5 次错误尝试后作废
- 验码成功后标记 `used_at`，不可复用

## 4. 环境变量

见 `backend/.env.example` 中 SMTP 段与 `docs/本地运行指南.md` §6.1。

## 5. 人工验收清单

请在本地配置好 QQ SMTP 后逐项勾选：

- [ ] 注册新邮箱 → QQ 邮箱收到 6 位验证码
- [ ] 验证码 + 密码注册成功 → Header 显示已登录
- [ ] 退出 → 密码登录成功
- [ ] 退出 → 验证码登录成功（先点「获取验证码」）
- [ ] 忘记密码 → 收码 → 设新密码 → 新密码可登录、旧密码不可
- [ ] 60 秒内重复点「获取验证码」→ 提示需等待
- [ ] （可选）老账号仍可用原密码直接登录
