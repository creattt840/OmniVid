# 阶段总结 — 转录质量门控（无语音视频幻觉修复）

> 完成时间：2026-06-16  
> 状态：**已完成，可验收**

## 一、背景与问题

对 3 条 B 站无对白/纯音乐测试视频（默剧、BGM、自动 CC 歌词误识别）进行评估后发现：

1. **Whisper 幻听**：`vad_filter=False` 时，纯 BGM 易被识别为俄语音乐标签、曲名等，ASR 幻觉率 100%。
2. **LLM 脑补**：垃圾转录仍会进入 DeepSeek 摘要/改写，总结幻觉率约 40%。
3. **产品误判**：3/3 视频在无有效人声时仍「假装分析成功」。

完整测试数据与打分见 [测试报告-无语音视频幻觉评估.md](./测试报告-无语音视频幻觉评估.md)。

## 二、已实施修复

### 2.1 Whisper 转写过滤（`transcriber.py`）

- 开启 `vad_filter=True`
- 丢弃 `no_speech_prob > 0.6` 或 `avg_logprob < -1.0` 的 segment

### 2.2 转录质量门控（`transcript_quality.py`）

在 `prepare_transcript` 前调用 `assert_transcript_quality()`，拦截：

- 有效文本 < 50 字
- 全文均为音乐/曲名标签
- 重复短句幻听
- 人声字符占比 / 语音时长占比过低

失败时返回明确错误：

> 未检测到足够的人声内容，无法生成可靠分析（…）。此类视频可能为纯音乐、默剧或仅含游戏音效。

### 2.3 摘要 Prompt 强化（`summarizer.py`）

- 转录不足时要求 LLM 勿编造 JSON 摘要
- URL 分析路径：字幕与 Whisper 均经质量门控
- 本地上传路径：用户主动上传的外挂字幕**豁免**门控（短 SRT 仍允许分析）

## 五、已知限制

- 门控阈值（50 字、5% 占比）为启发式，极短口播视频可能被误拒
- B 站自动 CC 与 Whisper 走同一门控；用户本地上传字幕不受字数门控
- 字幕下载接口仍可能产出 Whisper 幻听文本（仅分析链路拦截）
