# OmniVid 宝塔面板部署指南（零基础教学版）

本文档面向**第一次上线**的开发者，手把手教你用 [宝塔面板（BT Panel）](https://docs.bt.cn/) 部署 OmniVid。

**已验证环境（2026-03）：**

| 项目 | 配置 |
|------|------|
| 云厂商 | 腾讯云轻量应用服务器 |
| 系统 | OpenCloudOS 9 + 宝塔 Linux 面板 11.4 |
| 规格 | 2 核 4GB |
| 上线方式 | IP 内测（`http://公网IP/`，无备案） |
| Python | 3.11.6 / Nginx 1.30 / ffmpeg 7.0 |

> 以下步骤已在上述环境完成全链路验证：首页、B 站解析、登录验证码、AI 流式摘要。

---

## 上线方式选择

| 方式 | 适用 | 访问地址 |
|------|------|----------|
| **方案一：IP 内测** | 不备案、不买域名，自测或小范围分享 | `http://公网IP/` |
| 方案二：域名 + 备案 | 大陆服务器正式对外 | `https://域名/` |
| 方案三：香港/海外服务器 | 不备案 + 域名 + HTTPS | `https://域名/` |

下文默认 **方案一（IP 内测）**；域名备案与 HTTPS 见阶段 1、阶段 6。

---

## IP 内测快速路径（方案一）

按下面顺序做即可，**不需要买域名、不需要备案**。

| 步骤 | 做什么 | 预计时间 |
|------|--------|----------|
| 0 | 放行端口、准备密钥 | 10 分钟 |
| 2 | 安装 Nginx / Python / ffmpeg | 20 分钟 |
| 3 | 部署后端 + 配置 `.env` | 30 分钟 |
| 4 | 构建前端 + 创建网站（域名填 IP） | 20 分钟 |
| 5 | Nginx 反向代理 `/api` | 15 分钟 |
| 测 | 浏览器打开 `http://IP/` 全链路测试 | 10 分钟 |

**IP 内测专用配置（与正式域名的区别）：**

```env
# backend/.env
FRONTEND_URL=http://你的公网IP

# frontend/.env（构建前）
VITE_SITE_URL=http://你的公网IP
VITE_ICP_NUMBER=          # 留空
```

**限制（心里有数即可）：**
- 无 HTTPS 小锁，浏览器可能提示「不安全」（HTTP 正常）
- 不适合对外推广；以后若要正式上线，再买域名 + 备案或换香港服务器

## 一、先理解架构（1 分钟）

```
用户浏览器
    │ HTTPS
    ▼
  Nginx（宝塔网站）
    ├── /          → 静态文件 frontend/dist/
    └── /api/      → 反向代理 → FastAPI (127.0.0.1:8000)
                              ├── SQLite (omnivid.db)
                              ├── DeepSeek API
                              ├── yt-dlp + ffmpeg
                              └── QQ 邮箱 SMTP
```

- **前端**：构建后的 HTML/JS/CSS，放在 `/www/wwwroot/omnivid/`
- **后端**：Python 进程常驻，监听 `127.0.0.1:8000`（不直接暴露公网）
- **Nginx**：对外唯一入口，静态文件 + API 反向代理

本地开发时 Vite 代理 `/api`；上线后由 Nginx 做同样的事。

## 阶段 0：上线前准备（确认点 A）

### 0.1 准备密钥

| 材料 | 用途 |
|------|------|
| DeepSeek API Key | AI 摘要/转录 |
| QQ 邮箱 SMTP 授权码 | 注册/登录验证码 |
| JWT_SECRET | 用户登录安全（必须随机生成） |

**在本地 Windows PowerShell 生成 JWT：**

```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```

### 0.2 放行端口

1. **云厂商防火墙**（腾讯云：轻量服务器 → **防火墙**）→ 放行 **22、80、443、8888**
2. **宝塔面板** → 安全 → 放行 **80、443**

### 0.3 服务器配置建议

- CPU：2 核+
- 内存：**4 GB+**（Whisper 转写需要）
- 磁盘：**40 GB+**

✅ 完成后在 [deploy/checklist.md](../deploy/checklist.md) 勾选确认点 A。

## 阶段 1：购买域名 + ICP 备案（确认点 B）

> **大陆服务器必做**：未完成备案的域名**无法**在 80/443 端口正常对外提供网站服务。备案通常 **7～20 个工作日**。

### 1.1 购买域名

1. 登录 [阿里云域名注册](https://wanwang.aliyun.com/)
2. 搜索购买域名（如 `yourbrand.com`）
3. 完成**域名实名认证**（与备案主体一致）

### 1.2 提交 ICP 备案

1. 阿里云控制台 → **ICP 备案** → 开始备案
2. 填写主体信息、网站信息
3. 记录备案订单号

**备案等待期间**：可继续完成阶段 2～5，用 **服务器 IP** 内测（`http://你的IP/`）。

✅ 勾选确认点 B。

## 阶段 2：安装运行环境（确认点 C）

登录宝塔 Web 界面。

### 2.1 软件商店安装

| 软件 | 必须 |
|------|------|
| Nginx | 是 |
| Python 项目管理器（或面板内置 Python 项目） | 是 |
| Node 版本管理器 | 推荐（也可本地构建前端） |

> **不需要** MySQL、PHP。首次登录弹出的 **LNMP / LAMP / JAVA / Docker 一键安装** 请点 **× 关闭**，不要安装。

### 2.1.1 镜像选择（购机时）

- 选 **宝塔 Linux 面板** 应用镜像（不要选 Windows 版宝塔）
- 本地电脑上的 Windows 宝塔与云服务器系统无关

### 2.2 安装 Python 3.10+

宝塔 → **网站** → **Python 项目** → **Python 版本管理** → 安装 3.10 或 3.11。

### 2.3 安装 ffmpeg

宝塔 → **终端**：

```bash
# OpenCloudOS / CentOS / RHEL
dnf install -y ffmpeg

# Ubuntu / Debian
# apt update && apt install -y ffmpeg

ffmpeg -version
```

### 2.4 安装 Node.js 18+（可选）

软件商店 → Node 版本管理器 → 安装 Node 18 或 20。

### 2.5 上传/克隆代码

```bash
cd /www/wwwroot
git clone https://github.com/creattt840/video-downloader.git omnivid-src
```

若无 git，可用宝塔**文件管理器**上传整个项目到 `/www/wwwroot/omnivid-src/`。

### 2.6 运行环境检查

```bash
bash /www/wwwroot/omnivid-src/deploy/scripts/01-check-env.sh
```

全部 PASS 后继续。

✅ 勾选确认点 C。

## 阶段 3：部署后端（确认点 D）

### 3.1 复制后端代码

```bash
cp -r /www/wwwroot/omnivid-src/backend /www/wwwroot/omnivid-api
cd /www/wwwroot/omnivid-api
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
cp .env.example .env
```

> `cp` 需要**两个参数**：源目录 + 目标目录，例如 `cp -r .../backend .../omnivid-api`。

**pip 报 `Name or service not known` 时**，先修复 DNS：

```bash
echo "nameserver 114.114.114.114" > /etc/resolv.conf
echo "nameserver 8.8.8.8" >> /etc/resolv.conf
```

也可使用脚本：`bash deploy/scripts/02-setup-backend.sh`

### 3.2 编辑生产环境变量

编辑 `/www/wwwroot/omnivid-api/.env`（参考 [backend/.env.example](../backend/.env.example)）：

```env
JWT_SECRET=你生成的64位hex
DEEPSEEK_API_KEY=sk-你的密钥
FRONTEND_URL=http://你的公网IP
DATABASE_URL=sqlite:///./omnivid.db

SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USER=你的QQ号@qq.com
SMTP_PASSWORD=QQ邮箱16位授权码
SMTP_FROM=你的QQ号@qq.com
SMTP_USE_SSL=true
```

备案未完成时 `FRONTEND_URL` 可暂填 `http://你的IP`，备案通过后改为 `https://域名` 并重启后端。

### 3.3 宝塔创建 Python 项目

1. 宝塔 → **网站** → **Python 项目** → **添加 Python 项目**
2. 填写：

| 字段 | 值 |
|------|-----|
| 项目名称 | omnivid-api |
| 项目路径 | `/www/wwwroot/omnivid-api` |
| 启动方式 | 命令行启动 |
| 启动命令 | `/www/wwwroot/omnivid-api/venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000 --workers 2` |
| 运行用户 | www |

3. 点击**启动**

### 3.4 验证

```bash
curl http://127.0.0.1:8000/api/health
```

期望：`"status":"ok"`、`"ffmpeg":true`、`"ai_available":true`

✅ 勾选确认点 D。

## 阶段 4：构建并部署前端（确认点 E）

### 4.1 配置构建变量

编辑 `/www/wwwroot/omnivid-src/frontend/.env`：

```env
VITE_SITE_URL=https://你的域名.com
VITE_ICP_NUMBER=京ICP备xxxxxxxx号-1
```

`VITE_ICP_NUMBER` 在备案通过后再填；未填则不显示备案行。

### 4.2 构建（服务器）

```bash
bash /www/wwwroot/omnivid-src/deploy/scripts/03-build-frontend.sh
```

### 4.2 备选：本地 Windows 构建后上传

```powershell
cd e:\code\video-downloader\frontend
# 创建 .env 写入 VITE_SITE_URL 和 VITE_ICP_NUMBER
npm install
npm run build
```

将 `frontend/dist/` 内**所有文件**上传到宝塔 `/www/wwwroot/omnivid/`。

### 4.3 创建网站

1. 宝塔 → **网站** → **添加站点**
2. 填写：

| 字段 | 值 |
|------|-----|
| 域名 | **公网 IP**（只填 IP，不要 `http://`） |
| 根目录 | `/www/wwwroot/omnivid`（注意拼写，不要写成 omnivivid） |
| PHP | **纯静态** |

3. 浏览器用 **`http://公网IP/`** 访问（不要用 `https://`，未部署 SSL 会拒绝连接）

✅ 勾选确认点 E。

## 阶段 5：Nginx 反向代理（确认点 F）

### 5.1 宝塔 UI 添加反向代理

网站 → 你的站点 → **反向代理** → **添加**：

1. **开启「高级功能」**（否则看不到「代理目录」输入框）
2. 填写：

| 字段 | 值 |
|------|-----|
| 代理名称 | api |
| 目标 URL | `http://127.0.0.1:8000` |
| 发送域名 | `$host` |
| 代理目录 | `/api` |
| 开启缓存 | **关** |

### 5.2 修正宝塔自动生成的代理配置（必做）

宝塔默认生成的配置会把 `/api` 前缀去掉，导致 `/api/health` 返回 404。  
网站 → 反向代理 → **api** → **编辑配置文件**，替换为 [deploy/nginx/baota-proxy-api.conf](../deploy/nginx/baota-proxy-api.conf) 内容。

**关键差异：**

| 宝塔默认（错误） | 应改为 |
|------------------|--------|
| `proxy_pass http://127.0.0.1:8000/;` | `proxy_pass http://127.0.0.1:8000;`（无末尾斜杠） |
| `proxy_set_header Host 127.0.0.1;` | `proxy_set_header Host $host;` |
| 无 SSE 设置 | `proxy_buffering off;` + `proxy_read_timeout 600s;` |

### 5.3 修改站点主配置 server { }

网站 → **配置文件**，参考 [deploy/nginx/baota-server-snippet.conf](../deploy/nginx/baota-server-snippet.conf) 添加：

- `client_max_body_size 500m;`（在 `root` 行下方）
- `location / { try_files $uri $uri/ /index.html; }`（在 `include proxy` 之前）
- 建议注释 `error_page 404 /404.html;` 和 `include enable-php-00.conf;`

保存 → **Nginx 重载**。

### 5.4 全链路验证

```bash
bash /www/wwwroot/omnivid-src/deploy/scripts/04-verify-deployment.sh http://你的IP或域名
```

**手动测试：**

| 测试 | 期望 |
|------|------|
| B 站链接解析 | 出现视频信息 |
| 注册/登录 | 收到「OmniVid 验证码」邮件 |
| AI 摘要 | 流式输出文字 |
| 本地上传 | 小文件成功 |

✅ 勾选确认点 F。

## 阶段 6：备案通过后 HTTPS（确认点 G）

1. 阿里云 DNS：A 记录 `@` → 服务器 IP
2. 宝塔 → 网站 → SSL → **Let's Encrypt** 或阿里云免费证书
3. 开启**强制 HTTPS**
4. 更新 `backend/.env` 的 `FRONTEND_URL=https://你的域名`
5. 更新 `frontend/.env` 的 `VITE_SITE_URL` 和 `VITE_ICP_NUMBER`
6. 重新构建前端并覆盖 `/www/wwwroot/omnivid/`
7. 重启 Python 项目

参考宝塔文档：[为站点部署 SSL 证书](https://docs.bt.cn/)。

✅ 勾选确认点 G。

|------|------|

## 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `https://IP` 拒绝连接 | 未部署 SSL | 用 **`http://IP`** |
| `/api/health` 404 | 代理去掉 `/api` 前缀 | 改 proxy 配置，见 5.2 |
| `pip Name or service not known` | DNS 故障 | 改 `/etc/resolv.conf`，换阿里云镜像 |
| `cp: missing destination` | 只写了一个路径 | `cp -r 源目录 目标目录` |
| 首页空白 | 根目录拼写错误或 dist 多一层 | 确认 `/www/wwwroot/omnivid/index.html` 存在 |
| 反向代理无「代理目录」 | 未开高级功能 | 开启高级功能后填 `/api` |
| 域名 80/443 无法访问（大陆） | 未备案 | 完成 ICP；内测用 IP |
| Whisper 首次很慢 | 下载模型 | 正常，确保磁盘充足 |
| 刷新页面 404 | 缺 SPA fallback | 加 `try_files` |
| AI 中途断开 | Nginx 默认超时 | `proxy_buffering off` + `600s` |
