# 阶段总结：宝塔面板 IP 内测上线

## 部署结果

| 项目 | 内容 |
|------|------|
| 服务器 | 腾讯云轻量 2核4G，OpenCloudOS 9 |
| 面板 | 宝塔 Linux 11.4（应用镜像） |
| 访问地址 | `http://公网IP/`（IP 内测，无备案） |
| 验证项 | `/api/health`、B 站解析、登录验证码、AI 流式摘要 |

## 目录结构（生产）

```text
/www/wwwroot/omnivid-src/     # Git 源码
/www/wwwroot/omnivid-api/     # 后端 + venv + .env + omnivid.db
/www/wwwroot/omnivid/         # 前端 dist 静态文件
```

## 关键配置

- 后端：`uvicorn main:app --host 127.0.0.1 --port 8000 --workers 2`
- Nginx：静态 `/` + 反向代理 `/api/` → `127.0.0.1:8000`
- 代理配置必须去掉 `proxy_pass` 末尾斜杠，保留 `/api` 前缀
- 前端构建：`VITE_SITE_URL=http://公网IP`

## 踩坑记录

1. 购机镜像选 **宝塔 Linux**，不要 Windows 版
2. 首次登录 **不要** 一键安装 LNMP
3. `pip` 失败先修 DNS，换阿里云 PyPI 镜像
4. 访问用 **http** 不是 https（未部署 SSL）
5. 网站根目录注意拼写 `omnivid` 不是 `omnivivid`
6. 反向代理需开 **高级功能** 才能填 `/api` 目录
7. 宝塔自动 proxy 配置需手动修正（见 `deploy/nginx/baota-proxy-api.conf`）
