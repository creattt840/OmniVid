# 阶段总结 — 功能扩展与导航优化

> 完成时间：2026-06-14  
> 状态：**已完成，可验收**

## 一、本阶段目标

在已有「解析 + 下载 + AI 总结 + OmniVid 同屏工作区」基础上，对标 BibiGPT / NoteGPT 竞品能力，扩展笔记导出、字幕翻译、AI 改写文章、章节导航、分析历史、直链下载等能力，并将左侧汉堡菜单升级为全端侧滑导航。

## 二、已完成功能

### 2.1 AI 能力扩展

| 功能 | 说明 |
|------|------|
| 笔记导出 | 摘要 Tab 支持 Markdown / PDF 一键导出 |
| AI 改写文章 | 新增「文章」Tab，口语转书面语，Markdown 渲染排版 |
| 字幕多语言翻译 | 转录 Tab 支持 6 语言翻译并下载 SRT |
| 章节大纲导航 | 章节可点击跳转转录时间戳，支持原视频时间链接 |
| 分析历史 | 云端按用户保存最多 10 条，含转录/文章/问答，可恢复并继续对话 |

### 2.2 下载优化

- 优先调用 `/api/direct-url` 直链下载，失败自动回退服务端代理
- Toast 区分「直链下载」与「服务端代理」

### 2.3 左侧汉堡侧滑菜单（全端）

- 自左向右滑出 `SideMenuDrawer`，Esc / 遮罩关闭
- **工具区**：新建解析、分析历史、本地视频上传、使用帮助
- **了解区**：支持平台、功能亮点、定价方案

### 2.4 后续迭代（第 4.6 阶段已完成）

- **本地视频文件上传解析** → 见 [阶段总结-本地视频上传解析.md](./阶段总结-本地视频上传解析.md)

## 三、新增 API

| 接口 | 说明 |
|------|------|
| `GET /api/analyze/{id}/rewrite` | SSE 流式 AI 改写文章 |
| `POST /api/subtitles/translate` | 字幕翻译下载（en/zh/ja/ko/es/fr） |

## 四、新增前端模块

| 文件 | 职责 |
|------|------|
| `SideMenuDrawer.vue` | 左侧全端侧滑导航 |
| `HistoryPanel.vue` | 分析历史抽屉（右侧） |
| `api/history.js` | 分析历史 API（云端） |
| `ConfirmDialog.vue` | 删除确认弹窗 |
| `summaryExport.js` | 摘要 Markdown / PDF 导出 |
| `markdownRender.js` | AI 改写文章 Markdown 渲染 |
| `timeUtils.js` | 章节时间戳解析与视频链接构建 |

## 六、验收要点

1. 解析 → 下载 → AI 总结全流程正常
2. 摘要 Tab 导出 MD / PDF；文章 Tab 生成改写且排版正确
3. 转录 Tab 翻译下载 SRT；章节点击跳转高亮
4. 分析历史可保存、回看、删除
5. 下载优先直链，不可用则服务端代理
6. 汉堡菜单全端弹出侧滑抽屉
