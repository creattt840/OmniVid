# 万能视频下载网站 - 需求分析文档

## 1. 项目背景

用户有从各平台下载保存视频到本地的需求，但很多平台不支持直接下载，或存在清晰度限制、不支持批量下载、移动端不便等问题。本项目旨在提供一个统一的、跨平台的万能视频下载工具网站，随时随地快速保存视频。

## 2. 目标用户

- 需要下载在线视频到本地保存的个人用户
- 需要采集视频素材的内容创作者
- 需要在移动端随时下载视频的用户
- 想快速了解长视频内容、提升学习效率的用户（后续 AI 功能）

## 3. 核心功能需求

### 3.1 视频解析（P0 — 第一期）

- 用户粘贴视频链接，系统自动解析视频信息
- 展示视频标题、缩略图、时长、上传者、平台来源
- 列出所有可用的格式和清晰度选项

### 3.2 视频下载（P0 — 第一期）

- 用户选择清晰度/格式后，点击下载
- **服务端代理模式**：服务端下载后流式传输，浏览器 Blob 保存（兼容移动端与防盗链平台）
- **直链模式**（优化）：获取直链后浏览器直接下载，减少服务器带宽（后续优化）

### 3.3 多平台支持（P0 — 第一期）

- 基于 **yt-dlp** 开源项目，支持 1800+ 平台
- 国内平台专用解析：**抖音**（无水印）、**Bilibili**（绕过 412 反爬）
- 包括但不限于：YouTube、Bilibili、抖音、TikTok、Twitter/X、Instagram 等

### 3.4 移动端适配（P0 — 第一期）

- 响应式设计，手机浏览器也能正常使用
- 触屏友好的胶囊形输入框与大按钮

### 3.5 UI 设计要求（P0 — 第一期）

- 参考 [ai.codefather.cn/painting](https://ai.codefather.cn/painting) 的 UI 风格
- 浅灰页面背景、白卡片、饱和蓝主色、胶囊形输入框
- 标题高亮关键词、hashtag 标签化信息展示
- 突出实用价值，引导后续付费转化

### 3.6 AI 视频总结（P1 — 第 4 阶段，已完成）

- 总结摘要、字幕文本、思维导图、AI 问答
- 接入 DeepSeek 大模型，SSE 流式输出
- 思维导图全屏查看与 PNG/SVG/Markdown 导出
- 字幕独立下载（SRT/VTT/TXT，含 Whisper 兜底）

### 3.7 付费功能（P2 — 后续阶段）

- 免费版：基础下载 + 每日 AI 次数限制
- VIP 版：无限 AI 总结、4K 画质、字幕翻译、优先队列

### 3.8 扩展功能（P2 — 预留）

- 字幕翻译、下载历史、批量下载、Docker 部署
- 笔记同步（Notion / Obsidian / PDF）

## 4. 非功能需求

| 指标 | 要求 |
|------|------|
| 解析响应 | < 10s |
| 可用性 | 新用户无需学习即可使用 |
| 安全性 | 临时文件定期清理，不持久化用户视频 |
| 兼容性 | Chrome、Firefox、Safari、移动端浏览器 |
| 合规 | Footer 免责声明，仅供个人学习使用 |

## 5. 技术约束

- 以 **Python** 为主要技术栈
- 核心下载能力依赖 **yt-dlp** 开源项目
- 前后端分离架构
- 第一期无数据库，保持轻量；后续 VIP 功能引入 SQLite
