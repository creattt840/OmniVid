# 阶段总结 — 首页 AI 成果展示

> 完成时间：2026-06-16  
> 状态：**已完成，可验收**

## 一、本阶段目标

在首页 Hero 输入框下方增加**已完成 AI 分析**的成果预览，参考 BibiGPT 首页演示效果：用户未解析视频时即可看到摘要、转录、思维导图、改写文章等完整分析样例，并支持切换多条演示视频。

## 二、已完成功能

### 2.1 首页成果卡片

- 位置：Hero 输入框与营销区块之间，仅在未解析视频（`!videoData`）时显示
- 布局：与解析后工作区一致的 `workspace-card` 双栏（左预览 + 右 AI 分析）
- 左栏：缩略图、平台标签、时长、标题、可跳转原视频
- 右栏：复用 `VideoSummary`（embedded + `demoMode`），只读展示

### 2.2 切换演示视频

- 左栏下方「切换演示视频」折叠列表，参考 BibiGPT 样式
- 选中项实心主色高亮，未选中为白底卡片
- 切换后右侧分析内容随 `:key` 重载，**不发起 API 请求**

### 2.3 演示数据（静态 JSON）

- 数据文件：`frontend/src/data/demo-showcases.json`
- 当前内置 3 条演示：

  |------|------|
  | B站 | 从 LLM 到 Agent Skill（BV1E7wtzaEdq） |
  | B站 | Harness Engineering 一期讲透（BV1Zk9FBwELs） |
  | YouTube | Hermes Agent 保姆级教程（-EivK7vpOXY） |
- 兼容回退：`frontend/src/data/demo-showcase.json`（单条旧格式）

### 2.4 VideoSummary 演示模式

`demoMode=true` 时：

- 隐藏 MD/PDF 导出、AI 问答 Tab、转录导出/翻译
- 章节点击不跳转外链、不 seek 播放器
- 头部标注「演示数据」

### 2.5 数据生成脚本

```powershell
# 追加一条演示（需 backend/.env 配置 DEEPSEEK_API_KEY）
python scripts/generate_demo_showcase_direct.py "https://www.bilibili.com/video/BVxxxxx" --description "卡片副标题"

# 覆盖为单条
python scripts/generate_demo_showcase_direct.py "URL" --replace-all
```

脚本直接调用后端 `VideoAnalyzer`，避免 HTTP 超时；优先字幕提取，无字幕时回退 Whisper。

1. 首页未解析时，输入框下方出现双栏成果卡片
