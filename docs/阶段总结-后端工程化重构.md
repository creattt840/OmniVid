# 阶段总结 — 后端工程化重构与定价区体验修复

> 完成时间：2026-06-15  
> 状态：**已完成，可验收**

## 一、本阶段目标

1. 将 FastAPI 后端从根目录平铺结构重构为**扁平化工程化结构**（模式一：`api / core / db / schemas / services / tests`），参考 [FastAPI 项目工程化结构设计指南](https://blog.mapin.net/posts/FastAPI%20%E9%A1%B9%E7%9B%AE%E5%B7%A5%E7%A8%8B%E5%8C%96%E7%BB%93%E6%9E%84%E8%AE%BE%E8%AE%A1%E6%8C%87%E5%8D%97)。
2. 修复定价区「立即使用」按钮：登录后点击不应再次弹出登录窗口。

## 二、后端工程化重构

### 2.1 目录结构

```
backend/
├── main.py                 # 应用入口（~40 行）
├── pytest.ini
├── app/
│   ├── api/                # 路由层（统一 router.py 注册）
│   ├── core/               # config、dependencies、security/jwt
│   ├── db/                 # base、connection、models
│   ├── schemas/            # Pydantic 请求模型
│   └── services/           # 业务逻辑 + container 单例工厂
│       ├── video/          # downloader、bilibili、douyin、ytdlp_utils
│       ├── ai/             # summarizer、transcriber、subtitles、summary_parser
│       └── upload/         # local_upload
└── tests/                  # pytest + conftest.py
```

### 2.2 关键改动

| 项目 | 说明 |
|------|------|
| 路由拆分 | `main.py` 中 15 个端点拆至 `app/api/`（video、upload、analyze、subtitles、auth、billing、analysis_history 等） |
| 配置集中 | `app/core/config.py` 统一管理环境变量 |
| 循环依赖消除 | `app/services/container.py` 提供 `get_video_analyzer()` 等单例，替代 `analysis_history_routes → from main import video_analyzer` |
| 测试迁移 | `test_*.py` → `tests/`，独立临时 SQLite，19 项全部通过 |

### 2.3 刻意未改（YAGNI）

- 不引入 Repository 层、Async SQLAlchemy、Alembic
- 不迁移 `pyproject.toml` + uv，仍使用 `requirements.txt`
- API 路径前缀不变（`/api/*`），前端零改动

## 三、定价区体验修复

| 场景 | 修复前 | 修复后 |
|------|--------|--------|
| 未登录点击「免费使用」 | 打开登录弹窗 | 不变 |
| 已登录点击「立即使用」 | 错误地再次打开登录弹窗 | 滚动至页面顶部并聚焦 URL 输入框 |

涉及文件：`PricingSection.vue`（区分 `need-login` / `use-now` 事件）、`App.vue`（`handlePricingUseNow`）。

## 四、验收要点

1. `cd backend && python -m pytest tests/ -v` — 19 passed
2. `uvicorn main:app --reload` 启动无报错，`/docs` 端点完整
3. 前端联调：解析、登录、AI 分析、分析历史 CRUD 正常
4. 登录后点击定价区「立即使用」不再弹出登录窗口
