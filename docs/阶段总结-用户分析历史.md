# 阶段总结 - 用户分析历史与配额调整

## 1. 交付内容

### 分析历史（服务端）

| 模块 | 路径 | 说明 |
|------|------|------|
| 数据模型 | `app/db/models.py` → `AnalysisHistory` | 按用户隔离，每用户最多 10 条 |
| 业务逻辑 | `app/services/analysis_history.py` | 列表、保存/更新、删除、增量同步 |
| API | `app/api/analysis_history.py` | CRUD + 历史问答/改写 SSE |
| 测试 | `tests/test_analysis_history.py` | 隔离、上限、dedup、鉴权 |

**API 端点**

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/analysis-history` | 获取当前用户历史列表 |
| POST | `/api/analysis-history` | 保存/更新（支持 `partial: true` 增量同步） |
| DELETE | `/api/analysis-history/{id}` | 删除单条 |
| DELETE | `/api/analysis-history` | 清空 |
| POST | `/api/analysis-history/{id}/chat` | 基于历史继续 AI 问答（SSE） |
| GET | `/api/analysis-history/{id}/rewrite` | 基于历史生成改写文章（SSE） |

**持久化字段**：摘要、思维导图、转录 segments、改写文章、问答记录、元数据。

### 前端

| 文件 | 说明 |
|------|------|
| `api/history.js` | 历史 CRUD + 历史问答/改写 SSE |
| `ConfirmDialog.vue` | 删除/清空二次确认 |
| `HistoryPanel.vue` | 云端历史列表，未登录空态 |
| `App.vue` / `VideoSummary.vue` | 保存、恢复、增量同步、继续对话 |

### 配额与会员策略调整

| 项目 | 调整前 | 调整后 |
|------|--------|--------|
| 每日 AI 分析 | 免费 3 次 / VIP 无限 | **登录用户统一 10 次/日** |
| VIP 支付 | Stripe 开通 | **暂未开放**（checkout 返回 503） |
| 改写/翻译/PDF | VIP 专属 | **登录即可用**（仍受每日 10 次分析配额约束） |

环境变量：`FREE_DAILY_AI_LIMIT=10`（默认 10）。

## 2. 用户体验

1. 分析完成后自动保存至云端（需登录）
2. 点击历史 → 直接恢复摘要/转录/文章/问答，不重新消耗配额
3. 历史内可继续 AI 问答、补生成改写文章
4. 单条删除与清空均有二次确认弹窗
5. 历史徽章显示实际条数（1–10）

## 3. 不在范围

- 旧 localStorage 历史迁移
- 分析 session 归属校验（独立安全项）
- Stripe 会员重新开放（代码保留 Webhook，checkout 已禁用）
