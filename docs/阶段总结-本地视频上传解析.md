# 阶段总结 — 本地视频上传解析

> 完成时间：2026-06-15  
> 状态：**已完成，可验收**

## 一、本阶段目标

实现汉堡菜单「本地视频上传」功能：用户上传本地视频/音频文件，可选外挂 SRT/VTT 字幕，自动触发与 URL 解析相同的 AI 分析全套（摘要 / 转录 / 思维导图 / 文章 / 问答），并支持页内预览与章节跳转。

## 二、已完成功能

### 2.1 本地上传与分析

| 功能 | 说明 |
|------|------|
| 拖拽/点击上传 | `LocalUploadModal` 支持 mp4/mkv/mov/webm/mp3 等，最大 500MB / 60 分钟 |
| 外挂字幕 | 可选上传 SRT/VTT，有字幕时跳过 Whisper，分析更快 |
| 页内预览 | 左栏 `<video>` / `<audio>` 播放，章节点击 seek 跳转 |
| AI 分析全套 | 复用 `VideoSummary` 五 Tab，与 URL 模式一致 |
| 临时存储 | 服务端 `downloads/upload_{uuid}/`，TTL 30 分钟，shutdown 清理 |

### 2.2 体验修复（同阶段迭代）

| 问题 | 修复 |
|------|------|
| 上传后右栏残留上次分析 | `VideoSummary` 加 `:key` + 上传后 `nextTick` 强制重建 |
| 直链下载打开播放页 | fetch → Blob 下载，CORS 失败回退服务端代理 |
| AI 问答排版差 | 助手回复 Markdown 渲染，支持有序/无序列表 |

## 三、新增 API

| 接口 | 说明 |
|------|------|
| `POST /api/upload` | multipart 上传 media + 可选 subtitle |
| `GET /api/upload/{file_id}/stream` | 页内预览流 |
| `POST /api/analyze` | 扩展支持 `{ file_id }` 与 `{ url }` 二选一 |

## 五、验收要点

1. 汉堡菜单「本地视频上传」可打开弹窗，无「即将上线」标记
2. 上传 mp4 → 左栏预览 + 右栏自动 AI 分析（非上次内容）
3. 上传 mp4 + srt → 分析来源显示「字幕提取」
4. 章节点击 → 播放器跳转 + 转录高亮
5. URL 解析 → 下载 → AI 总结全流程不受影响
6. AI 问答回复排版清晰（标题、加粗、列表）
